# Natalna karta · WebGlow Studio

Besplatan alat na srpskom: natalna karta (precizan proračun, Placidus kuće, aspekti, tumačenje), uporedni horoskop (sinastrija), „Kristal za tebe“ i „Gledanje u šolju“ (za zabavu).

Proračun: [astronomy-engine](https://github.com/cosinekitty/astronomy) 2.1.19 (MIT), lokalno u `js/astronomy.min.js`. Statičan sajt, bez servera.

Napravio: [WebGlow Studio](https://webglowstudio.github.io/Webglowstudioportfolio/)
